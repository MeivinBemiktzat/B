# מדריך יצירת נכסים (Assets) - Escape Space Station

כל התמונות צריכות MidJourney / DALL-E / Leonardo.Ai / Stable Diffusion.
המלצה: **יחס תמונה 16:9**, רזולוציה **1920x1080** לרקעי חדרים, **512x512** לפריטים/אייקונים.
שמור בפורמט **PNG** (עם שקיפות לפריטים/אייקונים).

שים לב: כל שם קובץ למטה הוא **בדיוק** השם שהקוד מצפה לו. שמור בדיוק כך, כולל אותיות קטנות/רישיות.

## סיכום: איפה לשמור הכל

```
project/Content/
├── Images/
│   ├── rooms/         ← 6 קבצים (control_room, engine_room, laboratory, comms_room, emergency_room, corridor_hub)
│   ├── ui/            ← 5 קבצים (main_menu_bg, victory_bg, defeat_bg, panel_frame, button_normal/hover)
│   ├── items/         ← 10 קבצים (פריטים + לוחות חידה)
│   └── fx/            ← 3 קבצים
├── Audio/
│   ├── music/          ← 3 קבצים
│   └── sfx/            ← 7 קבצים
└── Fonts/              ← (הקוד ישתמש בפונט מובנה כברירת מחדל, אופציונלי להוסיף .ttf שלך)
```

**חשוב:** אם קובץ תמונה חסר, המשחק (כפי שבניתי אותו) ייפול חזרה אוטומטית לריבוע צבעוני placeholder כדי שלא יקרוס — כך תוכל להריץ ולבדוק את המשחק לפני שיש לך את כל הגרפיקה, ולהחליף בהדרגה.
